# P3 Game Assets

These assets were generated for FingerMemory with the built-in ImageGen tool on 2026-11-15.

## `companion-navigator.png`

- Original academy sci-fi training navigator, transparent RGBA background.
- Prompt intent: friendly young adult guide, deep navy/cyan uniform, restrained warm-pink edge light,
  practical study tablet, no text, logos, watermark, or sexualization.
- Runtime file was resized to a maximum dimension of 1000 px.

## `training-bay.png`

- Source background: original deep-navy academy training hall with a star field and cyan practice ring.
- No people, text, logos, or watermark.
- `training-bay.jpg` is the optimized runtime derivative used by the game workspace.
