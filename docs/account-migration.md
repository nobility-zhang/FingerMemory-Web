# 账号模式与本地数据迁移

状态：P2 原实现记录保留，2026-11-15 增补 G 阶段故事/策略迁移规划；新增部分尚未实现，不能套用 P2 的既有验证结论。

## 模式边界

- 本地模式继续使用 IndexedDB schema/data format v4，离线学习、会话、练习和本地正式复习保持可用。
- 账号模式以 Java 服务正式状态为唯一云端来源；账号模式正式复习第一版要求在线提交。
- 两种模式不自动双向同步。账号缓存、草稿和待确认提交按“服务器地址 + 用户 ID”隔离。
- 切换账号必须卸载旧模式、停止提醒、取消旧请求并清理账号私有页面缓存；本地模式数据库不删除。

## 首次登录迁移

1. 展示本地词库、词条、学习目标、笔记、练习、会话、复习状态和日志数量。
2. 显示目标服务器地址和账号用户名，要求用户主动勾选“上传到该账号”。
3. 上传前提供当前本地完整备份；用户不下载备份也可以取消迁移。
4. 生成本地稳定的 `migrationBatchId`，预览与确认使用同一快照指纹。
5. 服务端验证数据格式、ID、引用、调度版本、34 权重和日志链。
6. 服务端以 `(userId, migrationBatchId)` 建立唯一回执；同批次同内容返回第一次结果，同批次不同内容冲突。
7. 默认将上传内容作为独立导入集合追加；已有云端数据不被覆盖，不按词面自动合并掌握度。
8. 成功不删除本地数据；失败保留本地数据和待上传快照。

## ID 与日志映射

- 客户端提交原 ID 与稳定批次 ID，服务端在用户范围内保留无损字符串映射。
- 词条、学习目标、词库成员、笔记、会话、练习、复习状态和日志的引用必须在同一请求中保持一致。
- 卡片身份与学习目标映射一致；日志按 `reviewedAt`、`submissionId` 去重并保持 before/after 链。
- 已有云端状态与导入状态不合并。导入学习目标使用独立调度状态；若用户以后明确选择合并，另建设计和迁移。
- 导入历史标记 `source=migration`、`rewardEligible=false`；日志和旧会话不能重复产生经验、等级或成就。

## 版本与失败

- 迁移请求带 `sourceSchemaVersion`、`sourceDataFormatVersion`、`schedulerPackageVersion`、`schedulerModelVersion` 和配置哈希。
- 不兼容模型、损坏日志链、缺失引用和未来格式在写入前失败。
- 服务端在单事务中写导入集合、业务表、迁移回执和审计元数据；任一失败全部回滚。
- 重试使用原批次 ID；成功响应丢失后重试返回原回执和计数。
- P2 以用户范围内的 `fm_import_id_map` 保存原始 ID 到目标 ID 的映射；导入日志和奖励事件标记为不可奖励。

## 用户级备份

- 现有 IndexedDB“全库覆盖”只属于本地模式。
- 账号备份导出只查询当前认证用户的数据；管理员接口不能通过普通备份 API 绕过归属。
- 恢复先预览用户范围、版本和引用，再在单事务内替换当前用户业务数据；不删除账号、偏好、令牌或其他用户数据。
- 恢复失败保持当前账号数据不变。生产数据库备份与用户级 JSON 备份分开实现、验证和授权。
- P2 账号备份还保存正式复习回执、奖励事件、迁移回执和 ID 映射；恢复不触碰其他用户。


## G 阶段新增迁移边界

- 现有 v3/v4 词库、FSRS 与回执迁移继续有效；新卡片策略、冒险安装、存档和素材需要各自显式格式版本，实施时同步本地、Java、CLI 与备份校验器。
- 旧评估记录缺失 `assessmentPolicyVersion` 时解释为 legacy-v1，不套用新翻面规则重算旧日志；词条、学习目标和 FSRS 卡片 ID 保持原身份。
- 新导入 `.fmbook` 是内容安装，不是用户存档恢复：它不能携带并覆盖个人凭据、笔记、复习卡片、关系值或奖励。
- 普通 TSV 仍能只导入词库；绑定固定冒险模板要显式选择，不自动上传或生成冒险历史。
- 内容包的资源与数据库通过 staging/manifest 切换确保原子可见；坏包、资源缺失、冲突或取消不破坏已装版本。
- 进行中的冒险固定安装版本，升级须提供节点/词条映射。无法安全映射时保留旧 run，允许新建；不能无声重置 FSRS 或跳过未完成剧情。
- 帐号和本地备份新增故事、遭遇检查点、伙伴偏好、关系/奖励回执及不可变资源引用；私有资源须随归档或明确旁包导出，不能仅提供一个已失效的 URL。
- 用户恢复检查资源、状态引用和日志链，再切换可见数据；失败保持当前存档。本地与账号资料继续隔离，切号不共享故事草稿和迟到响应。
- 无旧故事的账号迁移后默认未开始冒险，不能用既有学习日志反向刷满关系和剧情；现有词汇熟悉度可用于选择教学队列，不等于重新发奖。
- 验收覆盖：v4→新版本、旧备份恢复、新故事归档往返、缺资源回滚、跨用户拒绝、包升级中断、同批次重试与恢复后奖励不重复。
