# FingerMemory 异世界伙伴与视觉交互方向

更新：2026-11-15。本文件替代旧“学园科幻训练舱”方向，是待实施的美术与交互规格。已有导航员与训练舱素材归入旧资产，不作为本轮立绘/背景验收成果。当前规划只定义制作需求，尚未生成以下新资产。

## 整体气质

中世纪异世界、温暖的 JRPG 旅途、视觉小说式伙伴对话，加上 2.5D 场景与回合制遭遇。参考作品用于世界与情绪方向，人物和剧情采用 `product.md` 的原创设定。首屏应让用户感到“莉娅在旅店等我一起出发”，而不是读到服务端队列、数据库版本或训练舱就绪。

场景元素包括石砌旅店、木梁、烛光、羊皮地图、森林、药草、古钟、星灯与魔法纹章；不使用电子屏、现代制服、霓虹数据线、机甲终端。中文阅读区用清晰正文无衬线，标题与地图标签可用有许可的衬线；输入区域保持稳定和高对比。

建议语义配色：墨棕 `#241B22`、纸白 `#F6EBD5`、酒红 `#8C4353`、森林绿 `#405C4C`、旧金 `#C8A66A`、星灯蓝 `#7EAFC3`。颜色只是初始方向，必须在背景、焦点、错误与评分状态下实测对比度。

## 页面与镜头

| 场所 | 构图与伙伴 | 主要动作 |
| --- | --- | --- |
| 暖灯旅店 | 手绘背景铺底，伙伴半身/全身站在一侧，桌上书本和地图可选；标题和对话保持留白 | 继续冒险、营地复习、选择词库与伙伴 |
| 旅途地图 | Three.js 正交/固定镜头微缩景观，节点与道路可点击，角色立绘独立在前景 | 选择路线、调查物件、查看章节进度 |
| 遭遇 | 中间为路障/敌人/队伍反馈，底部为卡片与行动指令，伙伴在侧边 | 回忆、翻面/提交、显式评分、选择技能 |
| 营火 | 温暖背景、伙伴表情与简短谈话，真实结算放在次级区域 | 休息、回看故事、保存退出 |
| 书架与设置 | 书封、冒险摘要、导入预览；管理操作仍使用明确的标准控件 | 导入、切换内容版本、备份、账号和偏好 |

默认桌面伙伴占可见区域约 25%–35%，不得遮挡问题/输入/评分。窄屏改为头像加短对白，可点开立绘；不能因为进入窄屏就完全消失陪伴入口。长英文、短语和多行中文不被花边或角色裁切。剧情文本无障碍可读，重要动作有文本替代。

## 角色规格与表演

角色设定以 `product.md` 为准，默认都是成年女性。莉娅体现温柔照料和略带害羞；瑟琳体现安静体贴和周到引导；菲妮带来有分寸的活泼与幽默。每个人应有区别于其他人的轮廓、服装、道具、语气、站姿和自身动机。

### 首批美术清单

| 资产 | 首段要求 | 后续扩展 |
| --- | --- | --- |
| 莉娅立绘 | 同一标准站姿，neutral/welcome/cheer/concern/relief/surprise 六个表情 | 提灯施法、递茶姿态，章节纪念 CG |
| 瑟琳立绘 | 同一标准站姿，同样六个表情 | 旅行杖护盾、整理笔记姿态 |
| 菲妮 | 第二章前完成标准立绘与上述六表情 | 探路与庆祝姿态 |
| 场景背景 | 暖灯旅店、失语森林溪桥、营火三张 | 药草园、古钟修道院、结局 CG |
| 书封与交互资源 | 第一部书封、路标、提灯、迷雾守卫、三种行动图标 | 每新内容包按实际节点补足 |

立绘源图建议 1024×1536 或更高的等比例竖图，透明 PNG，头顶、鞋子、手和道具完整。运行时生成合适尺寸的 WebP/PNG 衍生图，保留真实 alpha，禁止将棋盘格烘焙进图像。六表情共用画布、人物锚点、身高、光源和服装轮廓，换表情不能抖动或换脸。背景建议 16:9，适配竖屏时明确安全裁切区。

### 制作流程

1. 按角色设定生成一张标准立绘和角色设定参考；先检查面部、衣装、手部、道具和轮廓。
2. 将通过检查的标准立绘作为引用图，逐个编辑表情。只改变表情和必要的小动作，锁定身份、发型、衣服、构图和透明背景，避免六次从文字独立生成造成漂移。
3. 先完成莉娅一套并在真实旅店、训练界面检查，再以同一美术风格制作瑟琳和背景。
4. 检查透明边缘、发丝、重复肢体、裁切、缩小后的脸部可辨性及不同表情切换跳动。
5. 原图与运行时衍生图区分，资源清单记录角色 ID、表情、锚点、尺寸、工具/提示版本、文件哈希、来源与授权说明；不要把第三方素材误写为自有生成。
6. 使用会话可用的图像生成工具实际出图，不以 CSS/SVG 简笔头像、emoji、灰色人形或远程热链替代立绘。工具不可用时列出缺失资产及可直接执行的提示，继续不依赖它的工作，但美术任务仍标为未完成。

生成是离线制作步骤，不向产品引入 AI API。可由 DeepSeek 调用图像工具完成；这不要求 GPT 编写业务代码。本轮规划不预先宣称这些素材已存在。

### 可直接交给图像工具的提示

莉娅标准立绘：

> 为原创中世纪异世界 JRPG 制作一张可直接用于视觉小说对话的成年女性全身角色立绘。角色莉娅，温柔细心、略害羞但愿意主动照顾同伴，杏粉色长发与一侧编辫，柔和的琥珀色眼睛，奶油白与雾蓝的旅行裙装、短斗篷、小药草包，手提一盏古典暖光提灯。精致日式 RPG 商业插画，清晰线稿与柔和赛璐璐上色，友善轻微微笑，放松的站姿。完整呈现头顶、双手、提灯和鞋子，角色位于画布中央，身体周围留足透明边距，柔和统一的左前方光照。真实透明背景，不画场景、不画文字、Logo、水印或棋盘格；无科幻电子设备。以原创设计表达温柔旅伴气质。

瑟琳标准立绘：

> 与已提供的莉娅参考采用同一套精致日式 JRPG 线条、上色、光源和画布比例。原创成年女性旅行祭司瑟琳，安静细致、礼貌温柔，有自己的旅途目标；银绿色长发编辫，青绿色眼睛，苔绿披肩与象牙白长裙，独特叶形饰物、旧皮革记事册、木质旅行杖。完整全身、自然站姿，克制温暖的微笑。人物居中，双手和道具结构清楚，真实透明背景；保持明确成年外貌，不复制既有角色的脸、服装或标志性配饰，无文字水印、无科幻物件。

菲妮标准立绘：

> 延续已提供莉娅与瑟琳参考的美术质量与光源，原创成年女性冒险家菲妮，栗红发、琥珀眼睛、活泼可靠的神情，赭色短斗篷、实用皮革冒险服、长靴、地图筒与黄铜罗盘。轻快而不夸张的全身站姿，温和调皮的微笑。完整头顶到鞋底与道具，统一竖图构图、真实透明背景，无文字标志和科幻元素，人物身份独立且与两位同伴有明显轮廓差异。

表情编辑模板：

> 编辑引用角色的标准立绘，只把表情改为【welcome 温柔欢迎 / cheer 真心鼓励 / concern 关心但不责备 / relief 安心微笑 / surprise 轻微惊讶】。保持同一人、年龄感、脸型、发型、发色、服装、道具、站姿、身体比例、画布尺寸、人物位置和光照；保留真实透明背景。不得新增文字、场景、装饰或另一个角色。

旅店背景：

> 原创日式中世纪异世界 JRPG 场景背景，暮色中的暖灯旅店，木梁、石壁、暖色壁灯、壁炉、药草、木桌、羊皮地图和窗外远山；温暖安宁、带一点旅途幻想感，精致手绘游戏背景，与角色立绘匹配的柔和色彩。16:9 宽构图，左侧和中间保留人物站立及游戏界面的视觉留白，底部能叠加清晰的对话框；无人物、无文字、无现代设备或霓虹屏幕。不要把 UI 按钮画进背景。

溪桥/营火复用背景模板的画风，分别改为有路标与雾中石桥的森林、星空下安全温暖的营火，不变成完整界面截图。生成完必须在应用中检查，图片本身漂亮不等于合格布局。

## Three.js 互动与 DOM 分工

Three.js 提供固定镜头的微缩道路、可选热点、屏障、施法、护盾、敌人反应和节点切换。伙伴主要用高质量 2D 立绘与少量分层呼吸动画，首版不做全身 3D 角色建模或 Live2D 骨骼。

卡片、输入、自评、对白、菜单、保存状态继续由 Vue/DOM 提供，保证输入法、选择复制、焦点和读屏可用。开始回忆时冻结非必要场景操作；评分确定后才播响应，不因显卡慢漏掉学习事件。Three.js 没加载时也能用二维节点和文字完成同样任务。

第一章至少具备：选择路标触发对话、选路改变节点、护盾/破雾影响遭遇、章节结束改变世界状态。背景旋转、粒子漂浮或把原卡片贴到立方体上不算完成玩法。

## 快捷键与对话状态

沿用统一注册表并扩展上下文：camp、exploration、dialogue、recall、revealed、rating、action、paused、result。避免把原 `typing` 状态机硬塞满所有剧情逻辑。

- 空格：仅卡片 recall 状态翻面；在输入框中保持空格输入，在 dialogue 状态完成/继续当前句。
- Enter：提交拼写或确认当前已选项；一次物理按键只执行当前状态动作，不能穿透翻面后又评分。
- 1/2/3/4：只在 rating 状态评分；在 dialogue/action 中仅对明确标号选项生效；可输入控件优先。
- Esc：先关顶层弹窗，再暂停；返回不丢已提交进度和当前草稿。
- 方向键/Tab：按当前页面选择路线/行动或常规焦点移动，不能永久捕获焦点。
- 日志、跳过对白、关闭陪伴、专注模式和快捷键帮助都有可发现入口与可改键绑定。
- 不继承旧版冲突快捷键而不核查；macOS Option 字符输入、浏览器历史/下载键、IME、重复按键和粘贴都要测试。

## 声音与反馈

背景音乐默认关闭，音效和伙伴互动可独立静音。剧情可先用文字，不将没有录制的台词假装成完整语音。素材与音源须有明确来源；正式回忆前不自动发出会泄露答案的语音。

Again 后使用 concern/relief 与鼓励台词；不同评分不分配不同亲密度或经验。错误不让伙伴嫌弃玩家。减少动画时保留状态变化的静态反馈，避免仅以闪光、颜色或声音传达成功/失败。

## 美术与交互验收

- 同一界面可切换两位伙伴，面孔、语气和表情明显不同；相同角色六表情身份一致、无跳动。
- 旅店、溪桥遭遇、营火和经典卡片用真实资产与真实数据完成流程；不把原学园导航员作为已完成的新女主。
- 桌面 1440×900、常见笔记本 1366×768 和窄屏 390×844 检查文字、立绘裁切、焦点和对话；这些是验证目标，不表示目前通过。
- 默认减少动画、资源失败、离线、保存冲突、登录过期、长文案、后台恢复和 WebGL 不可用分别可用。
- 至少保留三张真实界面截图和一段第一章交互录像/操作记录，能看出“伙伴互动 → 学习 → 战斗选择 → 故事推进”；不能只交一张大厅图。
