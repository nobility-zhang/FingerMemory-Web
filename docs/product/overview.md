# FingerMemory 产品说明

更新：2026-11-16。当前目标为“中世纪异世界同龄少女伙伴陪伴的英语学习卡牌 JRPG”。新角色方向、音效和卡牌战斗均为待实施规格。现有旅店与伙伴组件可以复用；旧 Three.js 路线、溪桥三按钮规则以及歌词/弹幕/卡片雨独立模式被本规划替代。多用户、FSRS、词库冒险包、经典闪卡和 CLI 目标继续有效。

## 产品承诺与范围

用户希望打开应用时，感受到几位有性格、有立绘、有故事的同龄少女伙伴在等自己一起冒险；记忆单词是共同旅程中的行动。经典 Anki 式卡片始终是一等入口，可以跳过剧情和动画完成学习。

已确认要求：中世纪异世界背景、JRPG 氛围、多位关怀型伙伴、重新制作适龄立绘、使用主流 H5 游戏框架制作回合制卡牌互动、一部词库对应一段可导入和更新的冒险。用户提供的气质参照是《兰斯》的希露与《公主连结》的可可萝；世界氛围参照《兰斯》《Re:从零开始的异世界生活》《无职转生》《为美好的世界献上祝福》。采用温柔照顾、旅途陪伴、魔法与日常喜剧这些创作方向；新角色、地名、剧情、美术为原创，不把参考作品的情节当作本项目设定。

首轮完成可游玩的短篇闭环：两位伙伴、一个词库冒险包、一章包含探索与回合制遭遇的故事、可独立使用的翻面卡片。完整首部内容扩为三章与第三位伙伴，游戏以抽牌、能量、敌方意图、出牌顺序、牌组成长和英语学习题构成闭环。角色采用 14–16 岁的自然少女外观、轻便夏季旅行服与非性化表现。现有成年感/厚重旅行服素材需要重新制作，不能只改文字年龄。角色名、世界名和美术配色为默认创作方案。

运行时不接入 AI。立绘与背景可在制作阶段用图像生成工具制作；剧情、对白、规则和素材均打包后确定性运行。无开放世界、实时动作战斗、抽卡、体力收费、公开排名或远程代码插件的首版需求。

## 世界与故事

工作标题为《星灯旅团》，世界称为“弥尔兰”。失语之雾让道路铭文、古老契约和村民的书信逐渐模糊。玩家拥有“记文者”的能力，与伙伴恢复文字、连接村落并找回各自珍惜的记忆。语言学习可以表现为辨认路标、修复咒文、整理药剂说明和解读信件；不能为剧情编造错误词义，技术英语和考试词库也沿用原释义。

气氛是温暖旅店、森林遗迹、石桥、修道院、冒险公会、魔法与有分寸的日常喜剧。戏剧冲突来自旅途、误解和共同解决困难，伙伴不会因玩家忘词或几天没来而责备、冷落或扣好感。

### 第一章可直接制作的节点与对白

以下是样例包的起始脚本，作者可润色文字但保留可观察的分支与检查点。剧情界面不要提前显示尚待考核的英文词面。

| 稳定节点 ID | 内容与默认对白 | 选择与保存 |
| --- | --- | --- |
| `inn.arrival` | 莉娅把灯放在桌边：“信上的字又淡了一些。不过，寄信的人一定还在等回音。”瑟琳：“古钟修道院的印记还在。也许我们能沿着它找到路。” | 开始委托 / 先做营地复习；两条路径都能返回旅店 |
| `inn.preparation` | 莉娅：“我带了药草和热茶。你想先看地图，还是先读一小段信？” | 选择只改变伙伴短对白与 flags，不赠送记忆正确率或解锁答案；保存出发检查点 |
| `forest.signpost` | 点击倾斜路标与旧灯座。瑟琳：“先看清楚，再往前走。这次不用赶时间。” | 调查路标 / 查看灯座 / 扎营；调查两者合流到溪桥，不把必需学习内容藏在错过就消失的分支 |
| `bridge.guardian` | 莉娅：“桥在雾里。等你准备好了，我会把灯举起来。”进入明确的学习与行动界面 | 进入教学卡牌战斗；敌方意图、能量、手牌与目标明确可见；可随时撤退 |
| `bridge.crossed` | 瑟琳：“路标重新亮起来了。你刚才记下的东西，真的让这条路有了方向。” | 成功战斗获胜解除迷雾，设置 `bridgeResolved=true`；一次性记念事件 |
| `bridge.assisted` | 莉娅：“先抓住我的手。没关系，我们可以借着这盏灯慢慢走过去。” | 策略失败或请求救援也能过桥，保存 `bridgeAssisted=true`；不伪造新复习、不扣伙伴关系 |
| `camp.letter` | 第一段信恢复：“如果钟声还在，请告诉回家的旅人，灯一直亮着。”莉娅：“原来，等着回信的人不止我们。” | 休息 / 回看今日笔记 / 继续已安装章节；保存检查点 |
| `chapter1.end` | 镜头看向森林后的钟楼，瑟琳把信夹进旅记：“明天想从这里继续的话，我会替你留好这一页。” | 第一章结算与退出；后续未安装章节明确标记，不能跳空页面 |

样例词条可采用 lantern（提灯）、bridge（桥）、promise（承诺）及若干生活/旅行词；词义来自包内词库，剧情只提供情境。正式问答以前不把中英答案并排放在路标上；揭晓后的符文光效可展示已回答的词。

### 海滩支线 潮声海湾

第二章之后开放“潮声海湾”支线：旅团沿海寻找漂流信与熄灭的灯塔，经历沙滩探索、海边休息与一场复用卡牌规则的潮汐守卫遭遇。阳光、海浪和海鸟音效区别于森林，分支可以选择先调查潮汐路标或先整理漂流信，最终合流至灯塔。

伙伴在游泳/沙滩活动节点穿普通适龄泳装，使用自然活动姿态和普通镜头；不做身体部位强调或性化呈现。到村镇、进入遗迹等节点按内容配置换回旅行装。泳装是场景服装，不是付费属性装备，不改变技能、学习评分或角色身份。两位初始伙伴都应有对应服装与必要表情，不能以旅行立绘硬套海边背景宣称完成。

### 对白事件与节奏

对白由内容包中的固定文本与白名单变量组成，基于学习/故事事件选择；同事件从有限候选轮换，避免逐字实时生成。只在开场、显式评分后、休息、遭遇结果和章节节点出现，不在打字中抢焦点或覆盖答案。

- 欢迎：莉娅“热茶刚好。今天想先整理旅途笔记，还是去看看桥边的路标？”
- Again：瑟琳“这一枚符文还不熟悉。我们记下它，之后再一起遇见。”
- 完成小组：莉娅“这些已经收好了。接下来的路，我陪你慢慢走。”
- 主动休息：菲妮“地图不会跑掉。先在这里扎营吧，我来盯着篝火。”
- 离开多日后：莉娅“欢迎回来。上次的书签还在，你想从那里继续吗？”

提供安静、标准、丰富三档；标准档每小组优先至多一条主动陪伴短句，用户主动点伙伴不计此限。触发频率、重复抑制与台词版本是可配置数据。亲密度来自去重的共同经历与章节事件，和 Again/Hard/Good/Easy 等级无关；不按连续签到惩罚，不做刷重复点击的奖励。

## 核心玩法

产品只有两类主体验：独立的经典记忆闪卡，以及有规则、策略和剧情的英语学习游戏。键盘输入是学习题的作答方式，不另列为与游戏并排的第四种产品。歌词滚动、弹幕、卡片雨退出导航、模式设置和新会话创建；旧记录仍可读取、备份，未完会话显式转到经典学习继续或结束，不能直接删数据。

主游戏是合作旅途的回合制卡牌战斗，搭配章节地图、对话、营地和构筑奖励。默认使用 Phaser + Vue，采用 2D 手绘舞台和层次视差，不以 3D 镜头作为必要条件。

### 学习目标与战术牌分离

- 战术牌是技能、消耗和效果，如“守护”“余烬”；单词是具有学习状态的目标。词库仍是词库，不强制把一个单词做成一张永久战术牌。
- 每个玩家回合先分配一项真实词汇任务，默认“中文释义 → 英文拼写”；以后可增加有明确答案的例句填空。题目来自新词/到期队列，不随机重复已经学会的固定三词。
- 任务与回合绑定后冻结目标和题面，不因换牌、刷新或返回菜单换成更容易的词。战术牌名称、伙伴台词、背景和音效不得提前泄露当前答案。
- 显式评分/完成引导练习后获得本回合行动能量；一次事件只授权当前回合一次。复习状态只由统一学习核心维护。
- 玩家知道自己在“正式复习”还是“仅练习”。正式任务走 v2 规则与用户自评；仅练习不偷偷产生 FSRS 日志。不能把输入速度、匹配正确与战斗胜负直接映射为 Good/Easy。
- Again/Hard/Good/Easy 都授予相同的基础能量，避免自评选 Easy 才能赢。求助后可先明确记录 Again 再做引导练习；引导完成使用练习事件，不再补一份正式成功。
- 跳过不视为完成，可撤退到营地；没有强制倒计时，不因忘词扣友情。每日学习限额不足以发起下一回合时提示休息或明确选择纯练习继续，不能偷偷新增正式任务。

### 首版卡牌战斗规则

初始牌组 12 张，战前可查看全部内容；初版无需复杂卡包系统。一个遭遇每个回合抽 4 张、手牌上限 6、完成一项学习题得到 3 点能量。回合结束弃掉剩余手牌，能量不结转；抽牌堆空时把弃牌堆洗回，耗竭区不回洗。洗牌结果、卡实例 ID、抽取游标和规则版本进入存档，刷新不能重抽。

| 技能牌 | 初始牌数 | 消耗 | 效果 |
| --- | --- | --- | --- |
| 旅人突刺 | 3 | 1 | 对选中敌人造成 6 点伤害 |
| 同伴守护 | 3 | 1 | 队伍获得 5 点本回合格挡 |
| 余烬符文 | 2 | 1 | 造成 3 点伤害，施加 2 回合灼烧，每次敌方阶段开始结算 2 点 |
| 采药包 | 1 | 1 | 回复 4 点生命，不超过上限 |
| 观察路标 | 1 | 0 | 抽 1 张，使用后进入本场耗竭区，避免零费循环 |
| 旅团合击 | 2 | 2 | 对选中敌人造成 10 点伤害，优先消耗其护盾 |

效果白名单只包含 damage、block、heal、draw、apply-status、exhaust 等有限规则。首版不做任意脚本、递归连锁与复杂召唤系统。所有普通伤害先扣目标护盾，剩余扣生命；敌我生命不小于零。灼烧不叠加层数，重复施加刷新剩余回合。

回合顺序：清除玩家上回合剩余格挡 → 抽牌并公示敌方本回合意图 → 英语学习任务 → 确认结果/获取能量 → 自由选择出牌顺序和目标 → 玩家结束回合/弃牌 → 结算敌方灼烧 → 若敌人仍存活则执行意图 → 进入下一回合。敌人的护盾保留到消耗或遭遇结束。怪物/队伍生命为零分别进入胜利/营地救援，奖励和节点只结算一次。

首个教学遭遇“溪桥迷雾守卫”：队伍生命 30，守卫生命 36，意图按“攻击 6 → 获得护盾 6 → 攻击 8”循环。教学牌序固定，让玩家先理解格挡与能量；普通遭遇使用持久化的有种子洗牌。数值是可配置首测基线，目标一场约 3–6 个学习回合，实际平衡通过试玩调整，不能声称已经验证。

首章用两场战斗覆盖三类决策：面对攻击先格挡还是抢伤害、有限能量选择合击还是多张低费牌、当前治疗还是保留防守。敌方意图始终可见；伙伴提示描述战术，不替玩家回答英语问题。失败后回营地休整并保留已经提交的学习记录，不能为重打一场重置 FSRS。

### 构筑、伙伴与剧情

一次遭遇完成后提供三选一技能牌或休整选择，奖励来自包内固定池，发奖回执去重；不出售随机卡包。章节内获得的技能牌进入当前冒险牌组，同一内容重读不重复领取。营地可查看牌组和移除/替换本章奖励牌，牌组保持 12–18 张、同一定义最多 3 张；满组时选择替换或跳过奖励，奖励池过滤已达同名上限的牌。基础牌不会被删光导致卡死。

莉娅的伙伴技能回复 6 点生命，瑟琳提供 8 点本回合格挡，菲妮抽 2 张牌（仍受手牌上限约束）。首版每场可用一次、消耗 0 能量、仅在玩家出牌阶段使用，效果在敌方意图旁明确展示，不由友情等级强迫玩家选择特定角色。友情来自共同经历，不能购买答案、改变 FSRS 间隔或提高自评收益。

此前溪桥的“迷雾 2/屏障 2/三个按钮”方案停止实施，保留同名节点和对白并改为 `card-battle-v1`。一本书是一段有作者编写剧情的旅程；词库中的词通过学习队列绑定到章节任务，卡牌构筑由该故事包的规则与奖励定义。玩法可继续扩展，但新增类型必须拥有实际规则与验收，不把文字漂浮称作另一种游戏。

### 经典卡片与学习规则 v2

保留独立的 Anki 式“问题 → 心中回忆 → 翻面 → 自评”入口，以及键盘拼写入口。与冒险使用同一个学习目标和调度状态；同一目标不能因为换场景或伙伴创建新掌握度。

现有代码的 A1 把所有揭晓行为都排除出正式评分，不能直接承担翻面卡片。本轮明确设计 `assessmentPolicyVersion=2` 和三个不同流程，实施时必须修改前后端门禁、会话、API、日志校验与测试，不能只加一个翻面按钮。

| 流程 | 提交规则 | FSRS |
| --- | --- | --- |
| `flashcard-self-report` | 先呈现问题，玩家尝试回忆；翻面是检查结果，随后显式选 Again/Hard/Good/Easy | 翻面之后可以正式评分；“没想起”应能直接进入揭晓并选 Again，不能被迫编造一个错误答案 |
| `typed-recall` | 隐藏答案输入，提交后对照并显式评分；单词输入过程不泄露逐字正误 | 独立回忆记录有效；回答失败选择“没想起”可记录 Again；请求救助后不能再把抄对记成 Good/Easy |
| `guided-practice` | 看词、提示、跟读、抄写、预览或剧情中已展示答案后的练习 | 只记练习，不更新正式掌握度 |

自评无法证明玩家脑中的回忆过程，界面准确说明自评含义，服务端验证合法状态转换、显式评分和幂等，不声称能防止所有自评失真。提示前的失败通过明确 Again 事件留下；不能让遗忘总是只落入练习而导致调度长期高估记忆。

保留 A3 的同一学习目标同一会话至多一次正式提交；算法安排的下次学习步骤通过到期队列/下一会话发起。重复尝试只记练习。旧日志标为 `legacy-v1`，不回算、不补发遗忘或奖励，FSRS 引擎和参数版本不因此更换。

进入遭遇前按当前队列计划冻结目标与能力，区别阅读曝光与考核。剧情不能在正式提问前显示目标英文、答案译文组合或自动播放答案；若故事必须展示答案，该目标本回合进入 guided-practice。卡片使用 `assessmentType`；场景使用 `encounterType`；二者不合并为一个“游戏模式”枚举。

### 学习队列与剧情进度

- 待复习优先，保留新词量/复习量上限和暂停；不为看完一章强行添加几十个新词。
- 跨词库的到期项目可在营地处理，故事章节的新词来自该章节的显式绑定。
- 熟悉内容可以由当前状态判断跳过教学，具体章节资格记录在进度中，不靠词面推测共享。
- 章节能暂停在小检查点；当天没有待复习且不想学新词时可以看已解锁剧情、互动或退出。
- 经典卡片完成的有效事件可计入已激活的当前章节委托；同一事件不能在多本冒险重复领取同一种奖励，也不能回放旧日志刷关。

## 词库冒险包与扩展

一本词库对应一部有开端、推进和结局的冒险；词条数据与叙事资源分离但一起导入。定义 `.fmbook` 版本化 ZIP 包，最小包含清单、词条、章节/节点、对白、词条绑定、资源清单。契约、事务与包安全见 `docs/architecture/overview.md`。

- 成品故事包拥有作者编写的独立剧情与场景，玩家导入即能开始。
- 普通 TSV 仍能导入：可以只作为词库，也可显式选择“旅团委托”模板，按条目数量形成章节任务。此路径是固定模板实例化，不宣称为每本书自动创作全新故事。
- 内容作者可以制作新书包和章节更新，不修改应用代码；只能组合已注册节点/遭遇类型，不携带脚本。
- 包更新先预览变化，进行中的冒险固定在原版本，升级使用明确的节点/词条映射；不重置学习状态或重复发奖。
- 通关后提供重读与再探索，重复阅读不等于重复正式复习。
- 分享的内容包只包含内容和素材，不含私人笔记、账号凭据、个人 FSRS 状态或存档。

## 声音与素材

首版可以没有角色语音与单词发音，但必须有实际可听的 UI/游戏音效：悬停/确认、抽牌、出牌、卡片翻面、命中、格挡、治疗、能量补充、敌方回合、胜利和撤退。声音必须绑定真实事件并可静音/调音量，首次用户交互后解锁，不在页面打开时突然播放。细节与验收见 `docs/product/experience.md`。

## 多用户与 CLI

现有 Java + MySQL + 固定 TS-FSRS worker 继续作为账号模式边界，本地模式继续可独立使用。所有故事进度、伙伴偏好、亲密度、奖励和检查点都属于用户，和账号缓存、幂等、版本检查一起隔离。

CLI 继续在原仓库迭代，提供登录、词库、卡片/拼写、复习、备份和 `adventure list/start/resume` 等文字冒险入口。以同一内容图展示对白和选择，复用服务端进度，不要求终端渲染 Phaser 或立绘；用编号列出手牌、能量、敌方意图并执行同一战斗命令。节点都有文本降级说明；Web/CLI 交接从已提交检查点恢复，不传画面帧或动画时间。CLI 的卡片翻面与评分必须遵循学习规则 v2。

## 成功标准

- 首屏能看到中世纪场景、完成立绘的伙伴和继续旅程入口；页面不再出现训练舱、科幻终端等旧方向文案。
- 莉娅与瑟琳对同一学习事件有可辨的语气与表情；暂停、Again、回归和完成都有对应台词。
- 第一章可以从导入、选择伙伴、探索、学习、策略行动、营火结算一路玩完，再恢复继续。
- 卡片模式独立可用，翻面后可评分；未想起能正确记录 Again；抄写不被记录为成功回忆。
- 卡牌选择、费用、抽弃牌与敌方行动能真实改变战斗状态，弱设备可以完成等价二维流程。
- 两个内容包有独立故事进度；包升级、重复提交、断网、账号切换和恢复不会串档、重置 FSRS 或重复发奖。
- 用户能用快捷键完成卡片/冒险主要路径，输入法、辅助功能和减少动画设置有效。
- 每个可验证切片都有真实 Git commit 和验证记录；“文件写好了”不等于已提交或已完成。

具体实施顺序及既有 P/M 阶段记录以 `docs/development/roadmap.md` 为准。旧版技术验证不构成新叙事、美术、内容包或 卡牌战斗与音效的验收证据。
