# FingerMemory 伙伴 卡牌与音效方向

更新：2026-11-16。本文件定义下一轮目标。现有旅店和伙伴组件可复用；现有成年感、厚重服饰立绘需要重制。当前尚未实现新立绘、Phaser 卡牌战斗或本轮音效。本文件不保存逐轮验收报告，验收产物仅放 Git 忽略的本地目录。

## 角色方向

角色为 14–16 岁同龄少女伙伴，采用自然可爱、清爽夏季旅行风与非性化表现。画面表现友谊、冒险和共同学习，姿势、镜头和服装保持日常、适龄。以轻便棉麻、明亮配色和活泼神态解决冬装和成年感，不使用身体部位特写或挑逗姿态。

| 角色 | 年龄与气质 | 服装与识别要素 |
| --- | --- | --- |
| 莉娅 | 15 岁，温柔、略害羞、愿意主动帮忙的旅店伙伴 | 杏粉长发侧编辫，短袖棉麻上衣、雾蓝及膝裙、布包与轻便鞋，手提小灯 |
| 瑟琳 | 14 岁，安静细心、礼貌而有自己的想法 | 银绿编发，苔绿短袖上衣、象牙白及膝裙、叶形发饰，小记事册与轻便旅行杖 |
| 菲妮 | 16 岁，活泼可靠、有分寸地开玩笑 | 栗红发与琥珀眼，短袖上衣、日常旅行短裤、布腰包与轻便鞋，罗盘和地图筒 |

角色是同伴，台词兼具各自性格与自身目标；不使用成年照护者口吻，不因学习失败指责用户。保留欢迎、鼓励、关心、休息、惊讶、安心六类情绪；单次短句不抢输入焦点。

## 立绘实际制作

先重制莉娅标准图并放入真实旅店检查，再完成瑟琳和六表情。不要仅修改角色 JSON 中的年龄或给旧人物换发色；新脸型、神态、自然年龄比例与服装要一致体现本轮方向。

- 标准立绘使用透明 PNG，建议 1024×1536 竖图或等比更高分辨率，完整头顶、双手、鞋子和道具。
- 六表情以一张通过检查的新标准图为引用编辑，锁定脸型、发型、服装、构图、角色锚点和光照。
- 保持 neutral/welcome/cheer/concern/relief/surprise 资源键，减少组件改动；新素材制作完成并检查引用后再移除不再使用的旧素材。
- 成品原图、运行时压缩图和来源/许可清单可进入 Git；生成中间候选、比对拼图、录屏、截图和工具日志不得提交。
- 图像生成用于开发阶段，产品不接入 AI。工具不可用时将素材任务保留为未完成，不以占位图冒充新角色。

## 海滩服装与场景变体

海滩支线使用普通适龄泳装，描绘自然游泳、沙滩行走、拾贝或整理漂流信的活动；保持角色年龄、身份与非性化表现。采用普通平视或完整场景构图，不强调胸部尺寸或身体部位。服装不必与旅行装相同，角色一致性指同一人、脸型、发型与画风，而非所有场景都穿一套衣服。

角色资源扩展为“角色 ID → costumeId → expression”，至少支持 `summer-travel` 与 `beach-swimwear`；内容节点明确选择服装，离开海滩再切换旅行装。泳装变体从通过验收的角色身份参考制作，不能仅去掉旧衣层或换一张不一致的脸。保留六种情绪的表达能力，服装切换不丢表情和对白状态。

海湾背景提供沙滩、浅海、海边休息点与灯塔的正常景观；UI 留白与对话区域仍然清楚。海浪/海鸟为可控环境音，战斗音效与学习控件不受影响。该支线排在首章卡牌闭环后制作，但属于明确计划任务。

## 页面与卡牌布局

主入口为“继续冒险”“经典闪卡”“我的书架”；次级入口为伙伴、牌组与设置。移除歌词、弹幕、卡片雨的独立模式按钮和未完成占位项。

- 大厅：旅店背景、所选伙伴、冒险书与继续按钮；今日学习量是次级信息。
- 战斗：上方敌人、血量、护盾和明确意图；侧边伙伴与一次性协助；下方手牌、能量和结束回合按钮。
- 学习任务：在回合开始稳定显示释义/问题与原生输入或翻面卡片；此时暂停出牌输入，绝不同时抢键盘。
- 出牌：显示费用与完整效果，选择合法目标；鼠标可点牌再点目标，键盘可完整完成，不只依赖拖拽。
- 结算：剧情、所选伙伴反应与三选一战术奖励，真实学习结果简短显示。
- 经典闪卡：直接提问、翻面、自评，可以完全关闭剧情、伙伴和游戏音效。

技能牌与学习卡片要有不同的框架与标题，避免用户把“守护技能等级”误解为单词熟练度。手牌不显示当前英语题的标准答案；先回答再展示例句或词面。

## 游戏框架与表现

使用 Phaser 作为唯一游戏场景/动画/音效运行时，Vue 继续管理账户、书架、对白、手牌操作的 DOM 等价控件、输入与自评。通过显式事件桥和只读状态快照通信，不能同时让 Phaser 与 Vue 决定战斗状态。

采用 2D 手绘战斗舞台、卡面、粒子与有限视差。不额外接入 Three.js、另一套物理引擎或第二个音频框架。真实学习与出牌状态成功后再播音效和动画；动画结束不是业务提交。

## 快捷键

上下文至少区分 dialogue、learning-input、flashcard-front、rating、card-select、target-select、paused、result。

- 输入态 Enter 提交，空格正常输入，数字正常输入，IME composing 不提交。
- 闪卡正面空格翻面；评分态 1/2/3/4 评分。
- 手牌态数字 1–6 选择手牌；目标态方向键切换合法目标，Enter 确认；Esc 取消当前选择或关闭顶层弹窗，再暂停。
- 结束回合有独立可改组合键和按钮，不占用正常输入字符；帮助面板显示当前上下文的按键。
- 每次物理按键最多触发一次动作，event.repeat、弹窗穿透和状态切换残留监听必须处理。
- 不拦截常规 Tab、复制粘贴、浏览器和系统关键组合；所有战斗操作可不用拖拽完成。

## 音效为必做交付

可以没有语音和背景音乐，但不能只有“音效开关”而没有声音。首版使用许可明确的短音效或可复现的本地合成音效，加入成品资源与来源清单；不同事件听感应可区分。

| 事件 | 音效方向 | 触发条件 |
| --- | --- | --- |
| 选择/确认/取消 | 轻柔木质或纸面短音 | 有效交互，悬停做频率限制 |
| 抽牌/弃牌/翻面 | 轻纸张与短滑动 | 对应动作实际发生 |
| 获取能量 | 清亮单次星灯音 | 学习事件确认后，仅一次 |
| 出牌/攻击命中 | 短施法与轻打击 | 已确认动作的视觉播放，非重复请求 |
| 格挡/护盾 | 柔和屏障音 | 护盾产生/抵消伤害 |
| 治疗/伙伴协助 | 轻铃与暖色和弦 | 合法技能已执行 |
| 敌方回合 | 短低音提示 | 明确回合转换 |
| 胜利/营地救援 | 简短完成/归营音 | 一次性结算，不因刷新重新轰鸣 |

声音不念出答案，Again 不播羞辱性失败音。默认音效音量建议 35%，初次用户点击“开始”后解锁 AudioContext；静音与音量即时生效并持久化。声音锁定/设备无声不阻止学习，界面可提示点按开启。限制重叠音数和频率；切场景停止不再需要的循环音，后台暂停、切号、退出和卸载可靠释放。声音缺失应在开发诊断中可定位，不能静默当作已完成。

Phaser SoundManager 是 Game 级别，不因 Scene 切换自动停止声音；因此音效生命周期需要明确实现。参考：[官方音频说明](https://docs.phaser.io/phaser/concepts/audio)。

## 验收与文件归属

真实浏览器验证 1440×900、1366×768 和 390×844 的布局、焦点、卡牌目标、长文案及减少动画。至少亲自听到翻面、出牌、命中、格挡和胜利声音，验证静音、调音量、刷新偏好与首次交互解锁。

截图/录像/原始测试日志保存在 `.local/evidence/` 等被 Git 忽略的位置；源码测试、确定性 fixture、成品立绘/声音/许可说明仍应提交。验收清单属于长期规范，可以留在 docs；本次在哪台机器点了什么、截图路径、命令输出和聊天交接属于过程材料，不写进 Git 跟踪文档。
