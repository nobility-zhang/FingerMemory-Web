# FingerMemory 1.0.0 发布说明

状态：发布候选，2026-11-15。

## 发布制品

- 源码与锁文件位于 `web/`，应用版本为 `1.0.0`。
- 生产构建入口为 `npm run build`，制品位于 `web/dist/`。
- 制品是纯静态 HTML、CSS 和 JavaScript，不依赖 Node、Java、数据库或旧 Koa/Java 后端。
- 部署时发布 `web/dist/` 全部内容；应用没有服务端路由，不需要 API 或数据库迁移。

## 支持范围

- 目标设备：桌面键盘浏览器，窄屏布局保留完整操作路径。
- 已验证浏览器：当前 macOS 上的 Edge Chromium，使用真实 IndexedDB 和真实 DOM 交互。
- 未验证浏览器：Chrome、Firefox、Safari 和移动设备未在 1.0.0 最终轮逐一重跑。
- 开发工具链：Node 24.19.0、npm 12.0.2；生产运行不需要 Node。

## 数据兼容

- 当前 IndexedDB schema/data format 为 v4。
- v1/v2/v3 IndexedDB 数据按顺序迁移到 v4；旧练习会话队列缺失的来源会补为 `new`。
- 当前版本可预览和导入 v3 JSON 备份，写入前补齐队列来源并升级数据格式标志。
- 恢复仍会在单个 Dexie 事务中覆盖全部表；校验或写入失败时保留恢复前数据。
- v1.0 不读取旧 Java、Koa、MySQL、MongoDB 或 Redis 运行时数据。没有真实旧数据样本时不做迁移完成声明。

## 验证结果

- `npm test`：16 个测试文件、92 个测试通过，覆盖数据、导入、会话、FSRS、诊断、四种模式、提醒和千词发布夹具。
- `npm run check`：`vue-tsc --noEmit` 与 ESLint 0 warning 通过。
- `npm run build`：Vite 8.3.8 构建成功，191 个模块；主 JS gzip 约 135.8 kB，CSS gzip 约 8.2 kB。
- `npm audit --omit=dev`：0 vulnerabilities。
- 真实 Chromium 已验证 v3→v4 数据库升级、现有会话和复习日志保留、四种模式、评分预览、诊断、提醒和存储容量。
- 千词回归完成 1000 项目标导入、100 项队列计划、100 项会话、正式诊断和完整快照导出。

## 已知限制

- 应用内提醒只在应用打开时运行；关闭浏览器后的系统通知不在 v1.0 范围。
- 模式插件只能随项目构建并经过代码审查，不提供沙箱、远程安装或第三方运行时权限隔离。
- 不提供账号、云同步、多人协作和个人 FSRS 参数训练。
- 浏览器持久存储授权由用户和浏览器决定；未授予时不承诺存储不会被清理。
- 当前真实浏览器容量记录为使用约 112 KB、配额 10.00 GB；该读数只代表测试设备。
